# MyZetta: что изменено в прототипе по итогам тестирования

Прототип: https://dmitrysatin.github.io/zetta/

Визуальный стиль прототипа 65apps сохранён: токены, шрифт Inter, иллюстрации. Изменена логика по рекомендациям сводного отчёта о юзабилити-тестировании 21–25.09.2026. На изменённых элементах стоят фиолетовые значки ✎: что поменяли и на какую находку отчёта это опирается. Переключатель значков есть на стартовом экране, в ссылках для респондентов значки скрыты (`&notes=0`).

## Что осталось условным и требует сверки с Зеттой

Эти места в прототипе показывают предлагаемую логику. Возможна ли она, решают правила Зетты: см. раздел отчёта «Вопросы к правилам Зетты».

- Возврат на карту без реквизитов и подстановка паспорта из профиля — вопросы 2 и 3.
- Полис на главной — вопрос 4, по словам Надежды, мешает интеграция.
- «Паспорт и полис прикладывать не нужно» в форме гарантийного письма — наше предположение.
- Сроки ответа по гарантийному письму («обычно 1–3 рабочих дня»), состав программы «Стандарт», телефон и почта поддержки — условные данные.

## Проверка

Все пять заданий теста пройдены кликами в браузере без тупиков. Кнопка «назад» работает на всех экранах: если истории нет, она ведёт на главную. Каждый переход в коде проверен на наличие экрана. Разделы, которые в тестировании не участвовали (чат, SOS, медкарта и другие), открывают заглушку с кнопками «Назад» и «На главную».

- Задание 1: регистрация, пароль с подтверждением, код из 4 цифр дважды, главная с подсказкой.
- Задание 2: запись к хирургу — клиника «Чайка», слот, жалобы, подтверждение; запись появляется на главной. Отдельно проверена запись через оператора: клиника «Здоровье+», одна дата.
- Задание 3: переключение на ребёнка, профиль и полис ребёнка, запись к педиатру на Ивана.
- Задание 4: на главной нет заявок; плитка «Гарантийные письма», форма, отправка; письмо появляется в списке.
- Задание 5: чип франшизы, «Ваша часть за последние приёмы» — терапевт 337,50 ₽; счёт с раскрытием строки; возврат на карту; заявка в списке.

## Как устроено

Vite + React + TypeScript + Tailwind v4. Данные прототипа лежат в `src/data.ts`, экраны — в `src/screens`, общие элементы — в `src/ui`. Запуск: `npm install && npm run dev`. Выкладка на GitHub Pages: `./deploy.sh`.
